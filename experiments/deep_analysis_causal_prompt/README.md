## 报告要求

- 中文 TL;DR：约4–6句、180–260字，串起背景、已有不足、核心方法与收益。
- 正文：约900–1400字，保留背景与问题、关键观察与挑战、核心思路与设计、结果与总结四部分。
- 优先从 Introduction 提取主线，再从设计正文核对关键机制；设计解释问题、操作与效果之间的联系，实验只概括场景和主要结果。
- 推荐编号分条与加粗小标题，每点有充分解释；若论文更适合连贯叙述，可改用短段落，不强求条目或小标题，不凑数。
- 不增加独立局限性、问答或评论章节；关键结果保留最高、平均等限定。
